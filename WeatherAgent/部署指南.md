# 部署指南：把应用变成可访问的网页

目标：得到一个类似 `https://xxx.streamlit.app` 的公开链接，可以直接发给导师。

整个流程**不需要安装任何软件、不需要使用命令行**，只需要浏览器和两个免费账号。

---

## 准备

你需要：

- 一个 GitHub 账号（免费注册：<https://github.com/signup>）
- 一个 Streamlit 账号（用 GitHub 账号直接登录即可：<https://share.streamlit.io>）
- 本文件夹的全部内容

---

## 第一步：把代码传到 GitHub

1. 登录 GitHub，点击右上角 `+` → **New repository**。
2. 仓库名填 `weatheragent`（或任意名字），选择 **Public**，点击 **Create repository**。
3. 在新仓库页面点击 **uploading an existing file**（或 `Add file` → `Upload files`）。
4. 把本文件夹里的**所有文件和子文件夹**拖进上传区域。

   注意两点：

   - 一定要包含 `app.py`、`views/`、`tools/`、`data/`、`requirements.txt`；
   - **不要**上传 `data/raw/` 这个文件夹（它只是下载缓存，有 8 MB 左右，没必要上传）。

   （文件夹里还有 `__pycache__` 之类的目录，那是 Python 自动生成的缓存，
   GitHub 网页上传时如果一起传了也不影响运行，可以忽略。）

5. 点击 **Commit changes**。

上传完成后，仓库首页应该能看到 `app.py` 在文件列表里。

> **如果想把现有链接直接升级成这个版本**：不需要新建仓库，
> 直接在**原来那个仓库**里用 `Add file` → `Upload files` 把新文件传上去覆盖旧文件
> （注意 `views/` 是新增的文件夹，`data/` 里的 CSV 需要替换成新的）。
> 推送后 Streamlit 会自动重新部署，**原来的网址保持不变**。
> 上传前建议先确认新版本的首页能正常显示，再决定是否覆盖。

---

## 第二步：部署到 Streamlit

1. 打开 <https://share.streamlit.io>，用 GitHub 账号登录。
2. 点击 **Create app**（或 **New app**）。
3. 依次选择：
   - **Repository**：刚才创建的仓库
   - **Branch**：`main`
   - **Main file path**：`app.py`
4. 点击 **Deploy**。

首次部署需要 2—5 分钟。完成后你会得到一个形如
`https://weatheragent-xxxx.streamlit.app` 的公开链接。

**不需要配置任何 Secrets 或 API Key。** 应用默认使用离线研究助手，
所有数值都从仓库内的 CSV 数据实时计算得到。

---

## 第三步：验证

打开链接后，请依次检查：

1. 首页是否在 3 秒内显示出来；
2. 左侧导航的 10 个页面是否都能打开（「订正工具」页可以先点开看看，它默认载入内置示例数据）；
3. 「订正实验」页第一次打开会有几秒钟的计算（正常现象），
   之后因为缓存会很快；
4. 「真实案例」页切换两个过程时是否都能正常显示。

如果某一页报错，请把报错信息发给我。

---

## 常见问题

**应用显示 "Zzzz" 或要求唤醒。**
Streamlit 免费版的应用在长时间无人访问后会休眠。打开链接时点击
`Yes, get this app back up` 即可，唤醒约需 30 秒。
**如果导师可能随时点开，建议提前自己访问一次唤醒它。**

**部署失败，提示缺少模块。**
确认 `requirements.txt` 已上传。它列出了 pandas、numpy、scikit-learn、
plotly、streamlit、requests 六个依赖。

**中文显示成方框。**
本应用的图表由 Plotly 渲染，中文由浏览器字体处理，正常不会出现该问题。
如果出现，请告诉我使用的浏览器。

**想用自己的数据。**
把 `data/sample_weather_real.csv` 替换成同名文件即可，
列名保持 `time, forecast_temperature, observed_temperature, humidity,
pressure, wind_speed, hour, month` 不变，应用会自动读取。

---

## 如果想在本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

然后在浏览器打开 <http://localhost:8501>。

本地运行不需要联网——数据文件已经包含在项目里。
